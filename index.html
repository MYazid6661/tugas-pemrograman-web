 D. PROYEK & AKTIVITAS AKADEMIK 

1. Analisis Sistem Informasi Toko Berkah Rizki

Deskripsi: Melakukan analisis mendalam terhadap sistem operasional dan pencatatan transaksi pada Toko Berkah Rizki untuk mengidentifikasi kebutuhan digitalisasi sistem kasir dan inventaris barang.

Rincian Pengerjaan:

  • Identifikasi alur proses bisnis penjualan dan pembelian stok barang.
  • Pembuatan pemodelan sistem menggunakan Data Flow Diagram (DFD) dan Entity Relationship Diagram (ERD).
  • Rancangan usulan antarmuka (mockup) aplikasi kasir berbasis web sederhana.
  • Penyusunan rekomendasi perbaikan efisiensi stok opname barang.

2. Pembuatan Website Portofolio Pribadi (HTML Murni)

Deskripsi: Mengerjakan proyek mandiri untuk membangun halaman web portofolio statis dengan struktur tabel dan elemen dasar HTML5.

Rincian Pengerjaan:

  • Perancangan tata letak menggunakan struktur tabel interaktif.
  • Penerapan formulir kontak dengan rincian elemen input data.
  • Integrasi peta lokasi kampus menggunakan iframe Google Maps.

3. Perancangan Basis Data Toko Online Sederhana

Deskripsi: Merancang skema basis data terstruktur menggunakan MySQL untuk mendukung pengelolaan transaksi e-commerce skala kecil.

Rincian Pengerjaan:

  • Pembuatan tabel Pengguna, Produk, Kategori, Transaksi, dan Detail Transaksi.
  • Penerapan kueri SQL dasar (SELECT, JOIN, GROUP BY) untuk laporan penjualan.
  • Normalisasi data hingga bentuk normal ketiga (3NF).
